# Practice Engine

Topic-based active recall and spaced repetition with two-stage metacognitive review, AI auto-extraction, and interactive card database.

Source of truth: `Nihon/.obsidian/plugins/practice-engine/` v2.1.0. This repo is being reverse-engineered from the live bundled JS back to Obsidian-standard TypeScript.

Note: the previous GitHub `manifest.json` (`Practice & Assessment 0.1.0`) was a different lineage and has been replaced with the live plugin ID/version.

## Develop

- `npm i` (Node 18+), `npm run dev`, `npm run build` → `main.js`

Manual install: copy `main.js`, `manifest.json`, `styles.css` to `<Vault>/.obsidian/plugins/practice-engine/`.
